# Business Tracker (Salon Manager)

A bilingual (English/Spanish) web app for managing a small beauty salon: clients, appointments, stock and money. It's in real use by a working salon owner.

**Live app:** https://rayjon-moore.github.io/business-tracker

## Features
- **Clients:** add, edit and delete client records
- **Appointments:** with a WhatsApp booking link
- **Stock:** track products, with low-stock warnings
- **Money:** income, expenses and an automatic profit calculation with running totals
- **Service menu:** quick-select dropdown of the salon's real services and prices
- Everything saves in the browser (localStorage), so data stays after closing the page
- Confirm-before-delete pop-ups and form validation messages
- Fully bilingual labels in English and Spanish

## Built with
- HTML
- Tailwind CSS
- JavaScript (no frameworks)
- Hosted on GitHub Pages
